Global Readiness for Future Pandemics: A Comparative Analysis

This dissertation examines countries’ preparedness and resilience to future pandemics by combining cross-country indicators related to healthcare capacity, governance, digital connectivity, demographics, and population density.

The study uses data from 136 countries, combining 2020 pandemic outcome measures with the latest available data from 2024–25. The analysis involves data collection, cleaning, standardisation, exploratory data analysis, outlier detection, variable transformation, and regression analysis using R.

A multiple regression framework is used to investigate the relationship between excess mortality and factors including health expenditure per capita, trust in governance, internet penetration, elderly population, and population density. The study also develops a Pandemic Resilience Score (0–100) using weighted indicators to provide a comparative measure of countries’ preparedness for future health crises.
